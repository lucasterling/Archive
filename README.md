# Archive

**A native archive utility for macOS.**

Archive is a native macOS application for opening and securely extracting compressed archives, designed to feel at home on macOS.

The application currently focuses on RAR and ZIP archives, with support for password-protected archives, content inspection, selective extraction, progress tracking, and additional extraction safeguards.

## Preview

![Archive for macOS](Screenshots/archive-main.png)

## Features

- Open RAR and ZIP archives
- Drag and drop support
- Password-protected archive support
- Archive content inspection
- Search, filtering, and sorting
- Selective extraction
- Extraction progress
- Extraction cancellation
- Configurable extraction destination
- Recent archives
- Finder integration
- Optional notifications
- Localization support
- Native SwiftUI interface for macOS
- Extraction safety and validation mechanisms

## Requirements

- macOS 14.6 or later
- Apple Silicon and Intel Macs
